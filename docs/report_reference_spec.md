### 2.3 Полная таблица строк B (формулы)

> **Общее правило для формул в столбце B:**
> - SUMIFS → `=SUMIFS(Операции!$F$2:$F$1000,Операции!$B$2:$B$1000,">="&B$3,Операции!$B$2:$B$1000,"<"&EDATE(B$3,1),Операции!$C$2:$C$1000,"<Тип>",Операции!$D$2:$D$1000,"<Категория>")`
> - **Тип** = `"Доход"` или `"Расход"`; **Категория** = имя строки (Кейтеринг, Лавка, Бензин и т.д.)
> - **Для столбцов C–H**: ссылка на месяц заменяется `C$3`, `D$3`, … `H$3` (столбец меняется, строка $3 закреплена)
> - **Для столбца I**: `=SUM(B<I>:H<I>)`

> **Формулы SUMIFS по листу `Списания`** (строки 46, 53):
> `=SUMIFS(Списания!$G$2:$G$1000,Списания!$J$2:$J$1000,TEXT(B$3,"yyyy-mm"),Списания!$B$2:$B$1000,"<Группа>")`
> где `<Группа>` = `"Съели сами/взяли себе"` или `"Уточнить"`

> **Формулы SUMIFS по листу `Инвестиции`** (строка 57):
> `=SUMIFS(Инвестиции!$B$2:$B$1000,Инвестиции!$A$2:$A$1000,">="&B$3,Инвестиции!$A$2:$A$1000,"<"&EDATE(B$3,1))`

### 2.4 Формулы, ссылающиеся на другие строки отчёта

| Ячейка | Формула | Описание |
|--------|---------|----------|
| B10 | `=B11` | Доходы туроператора = сумма строки 11 |
| I10 | `=SUM(B10:H10)` | Итого по строке 10 |
| B12 | `=B4+B10` | Общая выручка = гастроферма + туроператор |
| B14 | `=SUM(B15:B25)-B45` | Прямые расходы минус "съели сами" из ERP |

| B38 | `=B39` | Налоги = строка 39 |
| B41 | `=B4-B14-B27-B38` | Прибыль = выручка − прямые − накладные − налоги |
| B42 | `=B41+B10` | Прибыль + туроператор |
| B48 | `=B41+B46` | Прибыль после корректировки (только гастроферма) |
| B49 | `=B42+B46` | Прибыль после корректировки (+ туроператор) |
| B52 | `=B32` | Подарки = справочная ссылка на строку 32 |

## 6. Отличия от текущей выгрузки (Google Sheets)

Исходники: `app/services/sheets.py` (функции `_format_report_sheet`, `_write_matrix_chunked`) и `app/services/report.py` (`report_to_matrix`).

| Аспект | Эталонный XLSX | Текущая выгрузка Google Sheets |

| **Столбцы на месяц** | 1 (сумма) | 2 (сумма + %) |
