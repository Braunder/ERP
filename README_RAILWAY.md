# Деплой на Railway

## Инструкция по деплою

### 1. Подготовка проекта

1. Создайте файл `.env` в корне проекта (уже создан)
2. Убедитесь, что в `.env` установлены правильные значения:
   - `DATABASE_URL` - путь к базе данных
   - `SECRET_KEY` - секретный ключ (сгенерируйте свой)
   - `ADMIN_PASSWORD` - пароль админ-панели

### 2. Деплой на Railway

1. Зарегистрируйтесь на [Railway.app](https://railway.app)
2. Создайте новый проект или выберите существующий
3. Нажмите "New Service" → "Deploy from GitHub repo"
4. Выберите этот репозиторий
5. Railway автоматически определит конфигурацию из `railway.json`
6. Нажмите "Deploy"

### 3. Создание базы данных PostgreSQL

1. В Railway dashboard нажмите на сервис вашего приложения
2. Перейдите в раздел "Variables"
3. Нажмите "Add Variable"
4. Создайте переменную `DATABASE_URL` со значением:
   - Railway автоматически создаст PostgreSQL базу данных
   - Формат: `postgresql://user:password@host:port/database`
   - Railway покажет значение после создания БД

**Важно:** Railway создаст базу данных автоматически при первом использовании переменной `DATABASE_URL`.

### 4. Настройка переменных окружения

После создания БД Railway предложит настроить переменные окружения:

**Обязательные переменные:**
- `DATABASE_URL` - подключение к PostgreSQL (создается Railway)
- `SECRET_KEY` - секретный ключ для подписи сессий
  - Сгенерируйте уникальный ключ: `python -c "import secrets; print(secrets.token_urlsafe(32))"`

- `ADMIN_PASSWORD` - пароль для админ-панели

**Опциональные переменные:**
- `GOOGLE_SA_FILE` - путь к файлу сервисного аккаунта Google Sheets
- `GOOGLE_SPREADSHEET_ID` - ID Google таблицы
- `SYNC_ENABLED` - включить синхронизацию (true/false)
- `SYNC_SCHEDULE` - расписание синхронизации (cron)

### 4. Настройка PostgreSQL

1. В Railway dashboard нажмите на сервис вашего приложения
2. Перейдите в раздел "Variables"
3. Нажмите "Add Variable"
4. Добавьте переменную `DATABASE_URL` со значением, которое Railway предоставит для PostgreSQL

### 5. Запуск миграций

После создания базы данных выполните миграции:

```bash
# В Railway Terminal (если доступен)
alembic upgrade head

# Или через SSH
ssh user@your-railway-app.com
cd /app
alembic upgrade head
```

### 6. Доступ к приложению

После успешного деплоя Railway предоставит URL приложения (например, `https://your-app.railway.app`)

Админ-панель доступна по адресу:
- `https://your-app.railway.app/login`

### 7. Первая настройка

1. Зайдите в админ-панель
2. Установите пароль администратора (если не задан в переменной `ADMIN_PASSWORD`)
3. Заполните справочники (категории, поставщики, продукты, сотрудники)
4. Начните использовать систему

### 7. Настройка домена (опционально)

1. В Railway dashboard нажмите на сервис
2. Перейдите в раздел "Networking"
3. Добавьте свой домен

## Переменные окружения для Railway

### Обязательные

| Переменная | Описание | Значение |
|------------|---------|----------|
| `DATABASE_URL` | Подключение к PostgreSQL | Автоматически создается Railway |
| `SECRET_KEY` | Секретный ключ | Сгенерируйте уникальный |
| `ADMIN_PASSWORD` | Пароль админа | Установите свой |

### Опциональные

| Переменная | Описание | Значение |
|------------|---------|----------|
| `GOOGLE_SA_FILE` | Файл сервисного аккаунта Google | Загрузите файл |
| `GOOGLE_SPREADSHEET_ID` | ID Google таблицы | Получите из таблицы |
| `SYNC_ENABLED` | Включить синхронизацию | `true` или `false` |
| `SYNC_SCHEDULE` | Расписание синхронизации | Cron выражение |

## Мониторинг и логи

- Логи приложения доступны в Railway dashboard
- Health-check эндпоинт: `https://your-app.railway.app/health`

## Резервное копирование

Railway автоматически создает бэкапы PostgreSQL. Вы также можете использовать встроенное резервное копирование приложения.

## Обновление приложения

1. Сделайте коммит изменений в GitHub
2. Railway автоматически перезапустит сервис
3. При необходимости выполните миграции: `alembic upgrade head`
